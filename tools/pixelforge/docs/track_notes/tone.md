# Tone of the Forge's text

The owner, on the Forge app's first screens: "the text doesn't need to be that dumbed down". The target is a
confident, adult tone, like a good game's menus and a good tool's labels: short, precise, no hand-holding, no
"nothing to set up" reassurance, no explaining what a painting is. Use the real words (turnaround sheet, palette,
frames, clips, atlas, preset) with a one-line definition available on hover or in the Advanced fold, not in the
main copy. Guidance belongs in the "what happens next" line and in the checks' notes, written as an expert would
write to a peer. Example: instead of "A turnaround sheet works best: the same figure from the front, the side and
the back on one plain background. A single front view works too." write "Drop a turnaround sheet (front, side,
back) or a single front view." Applies to the Forge app, the classic Studio, the CLI help and the guides.
