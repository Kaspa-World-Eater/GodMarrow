# The art library: chapters

Derek, 2026-10-07: "make chapters in the art repository so you can go back and reference them later."

Each study is its own chapter, written from the real world (sources noted), with a procedural recipe for every
material, so a piece can be built from the chapter and checked against it. Read the chapters that touch a piece
before starting it (MASTER_RULES section 1). `../STUDY.md` keeps the older rounds (1 to 13); new studies go here.
